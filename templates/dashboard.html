Project Overview

Behavioral Authentication Using Machine Learning

KeyGuard is a behavioral authentication system that uses keystroke dynamics to help verify user identity through typing behavior.

The system analyzes key hold durations and inter-key timing patterns to distinguish genuine users from impostors.
